# Segment Allocator

A Tkinter application for staff training in segmentation around TV behavioural questions
Introducing staff to audience segmentation.  
Guides staff through respondent entry, viewing preferences (Q1), 14 attitudinal statements (Q2), and exports data for batch analysis.

## Features

- Three-page GUI for Name, Q1, and Q2
- Validates all responses before allowing export
- Exports answers as a single row in .csv format, mapping dropdowns to codes

## Usage

1. Enter respondent name
2. Select one option for Q1
3. Choose one answer for each Q2 statement (dropdown)
4. Click Export to save results as CSV for batch analysis

## Exports

Access to marketing segmentation excel file will be needed to paste results
